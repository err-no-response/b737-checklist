# B738 Normal Checklist

A single-page Boeing 737-800 normal checklist for study and simulator use.

Open `index.html` in a browser, or host the repo with GitHub Pages.

This is **not** an official Boeing, airline, or regulatory document. Operator SOPs, the FCOM, and the QRH override it. Do not use it for real flight operations.

## Phases

Preflight, Before Start, Before Taxi, Before Takeoff, After Takeoff, Descent, Approach, Landing, After Landing (silent), Shutdown, Secure.

Checks and typed blanks (V-speeds, heading, altimeter, fuel, trim) are stored in the browser.
